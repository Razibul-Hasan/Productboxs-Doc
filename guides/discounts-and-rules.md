# Discounts and rules

The **Discounts** step is where you define how a box is priced and what shoppers can and cannot do.

## Basics

| Field | What it does |
| --- | --- |
| **Campaign name** | For you only. Shoppers do not see it. |
| **Campaign type** | Tiered discount, fixed box size or bundle price. |
| **Discount type** | Percent or fixed amount. |
| **Headline / Short intro** | Text above the builder. Lead with the number. |

## Rules

| Rule | Effect |
| --- | --- |
| **Box holds up to** | The most items a box can contain. |
| **Minimum to check out** | Below this the Add to cart button stays locked. |
| **Max of one product** | Limit how many of one product fit in a box. |
| **Allow the same product twice** | Off means each product can be added once. |
| **Allow coupons on this box** | When off, store coupons do not apply to this box. |
| **Hide sold-out products** | Otherwise they show as Sold out and cannot be added. |

## Tiers

Each tier unlocks when the box reaches its item count. Use **Add a tier** to add more, and the remove button to delete one. Tiers are shown to shoppers as steps at the top of the builder when **Show discount steps at the top** is on.

## Free gift

Add a product at no charge once the box has enough items. The gift goes in the cart with the box.

## Countdown timer

Show urgency without extra plugins. Count down to a time you pick, shown above the builder. It hides once that time passes.

* Show a countdown in the last 3 or 7 days before a campaign ends, or always.
* The campaign stays on after the end. Only the timer stops.
* Times use your **store time zone**.

## Schedule

Run a box **Between dates** to start and stop it automatically.

{% hint style="warning" %}
Coupons are off by default so they do not stack on box discounts. If you turn them on, shoppers can combine a coupon with the box discount. Keep them off for deep-discount boxes.
{% endhint %}
