# Publish a box

The **Publish** step checks your box and gets it in front of shoppers.

## Before you publish

If something is missing, the button says **Fix N things before publishing** and points you to each problem. Common ones: no products picked, an incomplete tier, or a missing bundle price.

## Where should shoppers find it?

| Option | What happens |
| --- | --- |
| **Create a new page** | We make the page and add the box. |
| **Add to a page I have** | Choose a page. The box goes at the top of it. |
| **I'll place it myself** | Use the block or the shortcode (below). |

## Use the block

In the block editor, add **ProductBoxes Box Builder** and choose a box.

## Use the shortcode

Click **Copy shortcode** and paste it anywhere shortcodes work.

```
[mmbb_box id="12"]
```

{% hint style="info" %}
See [Shortcode and block](../reference/shortcode-and-block.md) for every attribute.
{% endhint %}

## After publishing

The **Published** screen confirms the status and shows where the box lives. A published box shows a **Published** badge in the **Boxes** list.

## Turn all boxes off at once

Doing a stock count? In **Settings**, switch off **Box builders are on** to hide every box instantly, and switch it back on when you are ready.
