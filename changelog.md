# Changelog

## 2.0.0

A major redesign.

* Redesigned WordPress admin dashboard and box management.
* New **three-step editor** with a guided publish flow.
* **Live, theme-aware preview** for desktop, tablet and mobile.
* **10 customizable, responsive storefront templates**.
* Redesigned analytics and settings.
* Local fonts and accessibility improvements.
* WooPayments Multi-Currency compatibility.
* Astra and Blocksy compatibility.
* Better responsive layouts, keyboard navigation and publishing validation.
* Existing campaigns, boxes, orders, analytics, hooks, blocks and shortcodes are preserved.

## 1.0.0

Initial release with tiered discounts, fixed-size boxes, bundle pricing, storefront builder, cart and checkout support, analytics and settings.
