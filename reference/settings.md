# Settings

**ProductBoxes → Settings** holds options that apply to the whole store. Each box still sets its own look and discount.

## Box builders

| Setting | Description |
| --- | --- |
| **Box builders are on** | Turn off to hide every box at once, for example during a stock count. |

## Cart and checkout

| Setting | Description |
| --- | --- |
| **Show a box in the cart as** | Box name and price with items listed under it, or every item on its own line, grouped. |
| **Shoppers can edit a box from the cart** | Adds an "Edit box" link that reopens the builder. |
| **Main box page** | Used by "Edit box" links in the cart. |
| **Allow coupons on boxes** | Off, so coupons do not stack on box discounts. |

## Orders and stock

| Setting | Description |
| --- | --- |
| **List the items in each box** | In order confirmations and invoices. |
| **Include the gift note** | In your new-order email only, never the customer's. |
| **Reduce stock for each item** | Keeps WooCommerce stock counts right. |

## Data and privacy

| Setting | Description |
| --- | --- |
| **Collect box analytics** | Anonymous. Stays on this site. |
| **Keep detailed analytics for** | Enter a whole number from 7 to 730 days. The default is 90. |
| **Delete all ProductBoxes data when I uninstall** | Removes boxes, settings and analytics. Orders are never touched. |

Click **Save settings** to apply changes.

{% hint style="danger" %}
**Delete all ProductBoxes data when I uninstall** is permanent. Leave it off unless you are sure you want everything removed with the plugin.
{% endhint %}
