# Compatibility

| Area | Status |
| --- | --- |
| **WooCommerce** | 9.0 or later, tested up to 11.2 |
| **Cart and Checkout** | Classic and block-based |
| **HPOS** | Supported (High-Performance Order Storage) |
| **WooPayments Multi-Currency** | Supported. Campaign amounts and product prices convert correctly. |
| **Themes** | Works with WordPress themes in general, with added compatibility for **Astra** and **Blocksy** |
| **Editors** | Gutenberg block and shortcode |

## Themes

The live preview renders the box inside your **active theme**, so you see real colours, fonts and spacing. With **Match my site** on, the box inherits your theme's colours, fonts and button shape.

{% hint style="info" %}
Using a theme not listed? It should work. If something looks off, add **Custom CSS** on the Design step and let us know in the support forum.
{% endhint %}
